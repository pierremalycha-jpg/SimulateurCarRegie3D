CAR RÉGIE 3D — JOUER À PLUSIEURS SUR UN RÉSEAU LOCAL
====================================================

Une personne héberge la partie : son ordinateur fait tourner le serveur et le match.
Les autres n'installent rien : ils ouvrent une adresse dans leur navigateur.

1. SUR L'ORDINATEUR QUI HÉBERGE
   - Installez Node.js (version LTS) depuis https://nodejs.org (une seule fois).
   - Lancez le serveur :
       Windows : double-cliquez « Lancer le serveur (Windows).bat »
       macOS   : double-cliquez « lancer-serveur.command » (la 1re fois : clic droit > Ouvrir)
       Linux   : ./lancer-serveur.sh
       ou, dans un terminal : node car-regie-serveur-lan.mjs   (option : --port 9000)
   - La fenêtre affiche deux adresses :
       « Sur cet ordinateur : http://localhost:8080 »   → ouvrez-la vous-même
       « Pour les autres : http://192.168.x.x:8080 »    → donnez-la aux autres joueurs
   - Si Windows demande l'autorisation du pare-feu pour Node.js, acceptez pour les réseaux privés.

2. DANS LE NAVIGATEUR (tout le monde, hôte compris)
   - Ouvrez l'adresse, cliquez « Jouer à plusieurs ».
   - Choisissez un pseudo : il s'affiche au-dessus de votre personnage.
   - L'hôte : onglet « Héberger une partie », choisit son rôle, « Créer la partie ».
   - Les autres : onglet « Rejoindre une partie », choisissent la partie, leur rôle, « Rejoindre ».
   - L'hôte (ou le formateur) peut réattribuer les rôles : bouton « Équipe » > Participants.

3. LES RÔLES
   Réalisateur, truquiste, opérateur ralentis (EVS), ingénieur du son, ingénieur vision,
   technicien de car, habilleur, cadreur (une caméra chacun), formateur, observateur.
   Chacun pilote son poste ; les autres le voient en direct, en lecture seule.
   La fiche de rôle (en haut à gauche) rappelle la mission et suit quelques objectifs.

4. COMPTES RENDUS
   Le formateur enregistre le compte rendu de session : il est écrit sur l'ordinateur
   de l'hôte, dans le dossier « rapports » à côté du serveur (HTML et JSON).

Le serveur n'a besoin d'aucune connexion Internet : la page du simulateur est incluse.
Ctrl+C dans la fenêtre du serveur pour l'arrêter.
